Course Description: 
 Machine learning is now being applied to design sixth generation (6G) wireless communication systems. 
Objective of this course is to bridge the gap between theory of machine learning and its applications to wireless 
systems. To achieve the objective, this course will teach underlying machine learning concepts in the class. 
Students will then design various applications of machine learning for signal processing and wireless systems 
and implement using MATLAB/PYTHON/CUDA programming languages. Course will therefore involve 
MATLAB/PYTHON/CUDA coding component, which will also be considered for evaluation. 
At the end of the course, students will be able to understand and appreciate the machine learning model 
requirements specific for wireless communication systems, and design the models accordingly.

7. Course Description:
This course will introduce students to fundamentals of microprocessor and microcontroller architectures
(ARM, RISC,  etc.), instruction sets, pipelining, memories. Students  will learn to implement basic
computational algorithms using the open-source RISC-V architecture on FPGAs. Topics relevant for
developing embedded system applications such as interrupts, peripheral interface protocols, RTOS, etc. will
also be covered with the help of case studies.

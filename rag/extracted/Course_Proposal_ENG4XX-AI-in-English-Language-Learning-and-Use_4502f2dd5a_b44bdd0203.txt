6.  Course Description: This is an introductory course on using various tools to learn and use
English as a second language. This course provides not only theoretical insights on key
concepts and ethical issues but also practical training in using AI tools.

A) Objectives: Students will be able to achieve the following at the end of this course:
•  Understand the impact of AI on language learning and use
•   Illustrate how AI tools can facilitate learning and using English as a second language
•  Examine ethical aspects related to AI use
•  Compare traditional methods of language learning with AI-powered methods

C) Pre-requisites, if any (examples: a- PSO201A,or b- PSO201A or equivalent): -none-

D) A short summary for including in the Courses of Study Booklet

This is a UG-level course on AI and its application in language learning and use in real life. In
recent years, AI has significantly impacted all walks of life and language learning is one of them.
This course aims to discuss various AI tools and how they can be used to facilitate learning English
as a second language. Also, this illustrates the application of AI in real-life language use, with
examples. Finally, the course also examines the ethical aspects of AI use.

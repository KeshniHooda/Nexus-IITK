10. Objectives:
The objective of this course is to provide students with a practical understanding of systems security, with
an emphasis on binary analysis and instrumentation. Modern security analysis often requires
understanding, monitoring, and securing software at the binary level, particularly when source code is
unavailable, untrusted, or insufficient to reveal runtime behavior. Binary analysis, reverse engineering, and
instrumentation therefore play a key role in vulnerability discovery, malware analysis, exploit analysis,
and enforcement of security mechanisms. The course will cover memory-safety vulnerabilities and
defenses, static and dynamic binary analysis and instrumentation, vulnerability discovery, and reverse
engineering. A semester-long hands-on project will allow students to apply these concepts to analyze a
vulnerable program and progressively develop a working exploit.
